# SmartG — prototype PWA de test

Cette copie est destinée à la validation du prototype. Elle ne contient pas de système d'activation commerciale ni de validation par code après achat.

L'utilisateur crée uniquement un mot de passe local. Les données du coffre sont chiffrées dans le navigateur avec Web Crypto et restent sur l'appareil, sauf export manuel d'une sauvegarde chiffrée.

Le projet est statique : servez le dossier via HTTPS pour tester l'installation PWA et le service worker. Ouvrez `index.html` via un serveur web local, et non directement en `file://`.
